# Omnizero

项目名：Omnizero。

Omnizero 是面向 Windows 电脑的大型持久化沙盒 MMORPG。玩家从普通角色起步，在同一个持续发展的世界中生活、成长、经营，参与公会、国家治理与战争。

正式版与初版 Demo 均为 Windows 原生程序，目标引擎为 UE5，并将未来迁移至 UE6 纳入开发目标。首个可玩里程碑围绕建号选职业、新手村杀兔子、拾取与背包、死亡与复活展开。

当前项目处于需求设计阶段。文档分别标注已明确规则、设计草案和待定细节；规模数字属于设计目标，尚未完成承载验证。

从[设计文档索引](docs/AGENTS.md)开始阅读。主要入口包括：

- [世界设定](docs/world/setting.md)：世界背景、国家范围、地图与旅行。
- [角色体系](docs/characters/AGENTS.md)：职业规则、职业名录、进阶、成长与死亡。
- [组织与战争](docs/world/AGENTS.md)：公会、国家、人员管理、军令与战争。
- [经济与建设](docs/economy.md)：货币、交易、产业、领地与建设。
- [Demo 范围与技术目标](docs/demo.md)：首个可玩里程碑、平台、镜头与承载目标。

# 战斗、成长与死亡

[角色体系索引](AGENTS.md)

## 即时战斗

角色战斗采用完全即时动作，以"逆水寒"作为手感参考；具体操作细节待定。职业自带能力、装备与野技能之间的关系见[职业规则](professions.md)。

## 角色等级与死亡

- 角色等级不设上限。
- 达到 100 级的成长节奏目标约为 6 个月，日均游玩时长与经验曲线待定。
- 2000 级属于极难达成的阶段。极高等级的投入量级涉及实际现实货币，描述量级为几百亿，但具体币种、计价方式及经济模型尚未确定。
- 游戏内存在免费赚取所需收益、依靠运气达成高成长的可能，因此不能把固定现实付款额设为唯一达成条件。

## 死亡、复活与传送

- 默认每次死亡损失 1 级。
- 死亡扣级最低降至 1 级，达到下限后不再降低。
- 死亡掉落逐件独立判定。金银铜和绑定物品不掉落；魔晶石及其他未绑定物品参与判定，已穿戴物品也包括在内。稀有度越高，单次死亡掉落概率越低，与装备颜色等级无关。累计掉落效果的设计目标见[物品、装备与稀有度](../items.md)。
- 技能、武器或特殊效果可以加重死亡扣级，单次最高惩罚 100 级。
- "流放地"没有正常的系统复活殿。流放者在流放地死亡后于流放地传送阵复活，并直接损失 2 级；等级仍最低降至 1 级。该传送阵作为复活点是流放地特例；正式地图中的普通系统复活点是通常不具备传送功能的复活神殿。
- 已经完成新手阶段并离开的角色，因死亡掉级至低于 20 级时，直接在距离死亡地点最近的新手村复活，并重新受到新手区域限制。已完成的新手任务保留完成状态，重新达到 20 级即可再次离开新手区域。
- 已离开新手区域、死亡后仍为 20 级及以上的角色，通常在预先绑定的复活点复活；部分情况下使用最近的复活点。战斗状态下，复活地点不得离开战斗区域。
- 战斗状态下，绑定的复活点在战斗区域内时优先使用绑定点；绑定点在区域外时，使用战斗区域内距离死亡地点最近的可用复活点。
- 已经离开新手阶段的角色可以自由返回新手村及周边练级区域。整个新手村及周边练级区域禁止玩家之间互相攻击，不论角色是否已经完成新手阶段；怪物等非玩家造成的 PvE 伤害不受此限制。
- 允许围堵回城点和新手村大门。
- 所有复活均固定获得 3 秒无敌时间，不因区域、战争或其他玩法而缩短、取消或延长；系统强制迁移落地后同样获得 3 秒无敌。角色在无敌期间发起普通攻击、释放敌对技能、施加控制或执行其他主动敌对行为时，无敌立即取消，不等待命中或伤害结算；未发起敌对行为时可以在保护期内使用传送道具逃离。
- 极难获取且全球唯一的"国器"可以无视复活后的 3 秒无敌，对受保护角色产生效果。
- 逃离传送需要道具，角色技能无法实现；宠物具备特殊效果时也可以实现。
- 传送道具的成本设想为每件上千元人民币量级，具体获取途径、计价与经济模型待定。
- 传送的"稳定性"指落点的不确定性。3 秒内逃离时，基本无法选择目的地。
- 高品质道具将玩家传到最近 10 个传送点之一，具体选点方式待定。
- 低品质道具的落点混乱，可能传入坟墓、空气墙等位置，甚至因卡困而立即再次死亡。
- 更长施法时间如何改变落点的可控性、传送后无敌时间与环境死亡如何结算，待定。
- 复活点绑定与变更方式、特殊情况的具体复活规则、其他情况下的复活位置、特殊惩罚的叠加方式，以及 NPC 是否适用相同规则，尚未确认。

## NPC 等级与战斗难度

NPC 等级采用以下明确数值与参考档位：

| 类别或对象 | 等级 |
| --- | ---: |
| 一般村镇 NPC | 10–100 |
| 守城 NPC | 500–1,000 |
| 普通神祇、神殿基础神 | 1,000–2,000 起步 |
| 高位神祇参考档位 | 20,000、50,000、100,000 |
| 宙斯 | 1,000 |
| 鸿钧 | 20,000 |
| 大地之母、水、火、女娲、时间、空间 | 100,000 |

具体对象使用明确指定的等级，不依据称号另行推算。

等级差对战斗具有显著影响。100 级玩家面对 500 级守城 NPC，已接近只有高玩才能尝试的禁区，普通玩家可能擦边即死。挑战至少需要大量药物支持。跨越四百多级差距，可能涉及十几万元人民币量级的现实投入；即使操作水平高且投入资金，也仍然很难成功。

上述描述作为战斗难度与资源消耗的设计目标。具体战斗数值、药物种类与用量、获取途径、投入计算方式，以及多人配合的补偿程度，尚未确定；不能据此直接设置固定现实付款条件。

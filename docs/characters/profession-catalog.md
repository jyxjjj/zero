# 职业名录与阶位草案

[角色体系索引](AGENTS.md)

## 状态与范围

已给出的进阶路线继续保留，其余职业的阶位分配为本轮设计建议，尚未逐项确认。分组表示玩法方向；名称位于某个分组，不代表该分组内的所有职业处于同一阶位。某个分组没有列出某一阶位，表示当前名录尚未列出该项。

按名称去重后，当前名录共 233 个职业，包含此前保留的暗殿骑士以及进阶示例中的职业。当前阶位草案包括：

- 基础职业：54 个。
- 进阶职业：84 个。
- 高阶职业：68 个。
- 隐藏/特殊职业：27 个。

具体能力、前置关系和职业位占用仍需逐项定义。职业位与获取规则见[职业规则](professions.md)，已有路线见[职业进阶路线](progression.md)。

## 其他隐藏/特殊职业

黑暗龙骑士、龙语者、剑圣、武圣、圣者、大贤者、神眷者、神选者、神罚者、弑神者、魔王使徒、深渊行者、时空行者、位面行者、灵魂行者、死亡使者。

隐藏职业名录可以继续扩充。龙骑士、巫妖、兽神使、神工匠、神级炼金术师、古代机械师已按能力方向列入相应表格；与其他隐藏/特殊职业共同组成当前名录。每项职业具体属于隐藏职业、特殊职业，或同时具备两种属性，待随职业定义明确；隐藏职业的完整名录不会展示在建号界面。

名录允许交叉归类。例如，猎人出现在战斗与采集分类，机械师出现在建筑工程与科技分类，龙骑士和巫妖同时具有能力分类与隐藏职业属性。重复列名本身不产生额外职业或额外占位。同名职业是否需要拆分不同分支、相近名称之间是否存在别名关系，待逐项定义；黑骑士与黑暗骑士、亡灵骑士与死亡骑士等目前分别保留。

# 职业名录与阶位草案

[自动计算与平衡规则索引](AGENTS.md)

## 状态与范围

进阶路线以[职业规则](../user-rules/characters/职业规则.md#进阶路线)为准，其余阶位是草案，还没逐项确认。名录按玩法方向分组，同组职业可以处于不同阶位。某组没写的阶位，只是还没列进名录。

同名职业只算一次，共 233 个，阶位分配如下：

- 基础职业：54 个。
- 进阶职业：84 个。
- 高阶职业：68 个。
- 隐藏/特殊职业：27 个。

各职业的能力、前置条件和占位数量还没定，职业位与获取方式见[职业规则](../user-rules/characters/职业规则.md)。

建号开放范围见[首个 Demo](../user-rules/演示目标.md#首个可玩里程碑)，基础职业见各分组。

## 其他隐藏/特殊职业

黑暗龙骑士、龙语者、剑圣、武圣、圣者、大贤者、神眷者、神选者、神罚者、弑神者、魔王使徒、深渊行者、时空行者、位面行者、灵魂行者、死亡使者。

隐藏职业名录可以扩充。龙骑士、巫妖、兽神使、神工匠、神级炼金术师、古代机械师按能力列在各分组，与本节共同组成隐藏/特殊职业名录。各职业属于隐藏、特殊还是两者兼有，按职业分别确定。

职业可以交叉归类：猎人属于战斗和采集，机械师属于建筑工程和科技，龙骑士、巫妖同时有能力分类和隐藏职业属性。交叉归类不会增加职业数量或额外占位。同名职业是否拆分支、相近名称是否为别名，都还没定；黑骑士与黑暗骑士、亡灵骑士与死亡骑士分别列出。

## 货币与交易

货币分为三套体系：

| 体系 | 单位与兑换规则 |
| --- | --- |
| A | 金、银、铜；1 金 = 1,000 银 = 1,000,000 铜 |
| B | 白、绿、蓝、红、紫、彩、黑、粉、金九种颜色的魔晶石；汇率由游戏内玩家交易形成并浮动 |
| C | 真实世界货币与游戏的兑换：充值按 1 CNY 换 1 铜；玩家可以在充值系统之外自行交易金银铜 |

A 与 B 可以通过交易双向兑换，魔晶石不能自动升级。金银铜放入背包后，按进位规则自动向上合并，不需要场景交互；金银铜具有重量。币种重量及合并后的负重计算、自动拆零与找零规则待定。

死亡掉落规则中，金银铜不掉落，魔晶石参与物品掉落判定，具体规则见[物品、装备与稀有度](items.md)。

一般情况下，1,000 金可兑换 1 白魔晶石；这是玩家市场中的常见水平，具体成交汇率可以浮动。体系 C 的官方反向兑换、玩家交易的定价与结算方式待定。

## 产业、领地与建设

经济由 NPC 与玩家共同推动。NPC 拥有产业与需求，可以生产、交易和雇佣；玩家在同一个经济体系中经营、竞争与合作。

普通玩家或新公会可以通过购买、开拓无主地、任务奖励，以及借助 NPC 军队和攻城器械夺城，获得第一处领地。这些途径同时存在，各途径的取得条件、成本与权属规则待定。

建设采用模块化自由布局，可以组合建筑、墙体、道路、机械和生产线。地形改造范围、各类土地的取得条件、资源再生、生产配方、物流规则和建设成本待定。

正式地图中的传送阵属于需要花钱建设的特殊地点。全世界首次传送功能必须先由玩家通过奇遇发现，之后才能进入相应的建设与使用阶段；具体费用和规则待定。

## 流放地经济

国家灭亡后的流放者会进入不在正式地图上的"流放地"。流放地中的药品等物资价格提高 5%；适用物资范围与基准价格待定。

## 货币与交易

货币分为三套体系：

| 体系 | 单位与兑换规则 |
| --- | --- |
| A | 金、银、铜；1 金 = 1,000 银 = 1,000,000 铜 |
| B | 白、绿、蓝、红、紫、彩、黑、粉、金九种颜色的魔晶石；汇率由游戏内玩家交易形成并浮动 |
| C | 真实世界货币与游戏的兑换：充值按 1 CNY 换 1 铜；玩家可以在充值系统之外自行交易金银铜 |

A 和 B 可以交易互换，魔晶石不能自动升级。金银铜放进背包就按进位自动向上合并，不用场景交互，但有重量。币种重量、合并后负重怎么算、自动拆零和找零还没定。

货币的死亡掉落范围见[死亡掉落](物品装备.md#死亡掉落)。

玩家市场通常 1,000 金换 1 白魔晶石，成交汇率可以浮动。体系 C 的官方反向兑换，以及玩家交易怎么定价、结算，还没定。

## 宠物交易与黑市

常规购买只能买宠物蛋。玩家可以自由犯罪，黑市买卖没有系统硬性限制，但各国、各城、其他玩家和各类神殿会打击。

## 产业、领地与建设

NPC 和玩家共用经济体系。NPC 有产业和需求，能生产、交易、雇佣；玩家也在其中经营、竞争、合作。

普通玩家或新公会的第一块领地，可以买、开拓无主地、做任务拿，也可以借助 NPC 军队和攻城器械夺城。这些方式同时存在，各自条件、成本和权属规则待定。

建设用模块自由布局，可以组合建筑、墙体、道路、机械和生产线。能改多少地形、各类土地怎么拿、资源再生、生产配方、物流规则和建设成本还没定。

传送阵的发现、建设与使用见[传送设施](world/世界设定.md#传送设施)，流放地物价见[流放地](world/亡国流放.md#流放地)。

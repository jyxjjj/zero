# 背包与空间存储

[用户规则索引](AGENTS.md)

## 容量与负重

- 背包按物品占用的体积空间限制容量，不设格子数量限制。
- 普通背包有负重限制。越重走得越慢，最严重时动不了，玩家自己想办法处理物品。
- 高级空间系道具可以只有体积限制，没有负重限制。
- 部分宠物可能拥有可以存放物品的空间技能。

## 普通储物空间与界

空间系技能分普通储物空间和“界”，“界”的正式名字还没定。普通储物空间不能放活物，只有“界”可以。

“界”像小世界，有完整活动空间、景色，自带观赏性和可食用的动植物等。宠物怎么吃、动植物怎么恢复，见[饥饿与饥渴](characters/成长死亡.md#饥饿与饥渴)。

特殊宠物的“界”类空间技能可以收纳主人的所有宠物，按宠物实际体积占空间。空间不够也能硬塞，只要宠物不怕疼，但可能持续掉血。宠物位占用见[宠物规则](characters/宠物召唤仆从.md#宠物)。

## 宠物召唤空间

每只宠物另有独立召唤空间，彼此不能交流。里面黑乎乎的，什么都没有，也不存在“界”的硬塞规则。

召唤空间暂停时间，饥饿、饥渴也暂停。但宠物知道自己被收进去了，兴奋、活跃照样降低，怎么影响忠诚度见[宠物行为](characters/宠物召唤仆从.md#忠诚与行为)。

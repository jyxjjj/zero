# Demo 范围与技术目标

[用户规则索引](AGENTS.md)

## 平台与引擎

- 只支持 Windows，用键盘和鼠标操作。
- 正式版与初版 Demo 均为 Windows 原生程序。
- 引擎用 UE5，小版本待定，后续要能迁移到 UE6。

迁移按官方升级路线做，职业、战斗、世界状态和资源都要测兼容性。Epic 的计划是早期 UE6 保留 Actors 和 Blueprints，后续提供框架转换工具；本项目能兼容到什么程度，要实际测试。[UE6 官方路线图](https://www.unrealengine.com/news/the-road-to-ue-6)

## 首个可玩里程碑

首个 Demo 做新手村，按这个顺序测试：

| 顺序 | 体验 | 规则依据 |
| ---: | --- | --- |
| 1 | 建号与职业位选择 | [账号身份](账号身份.md)、[职业规则](characters/职业规则.md) |
| 2 | 新手村出生 | [新手历程](characters/新手历程.md) |
| 3 | 杀兔子 | [即时战斗](characters/成长死亡.md#即时战斗) |
| 4 | 拾取与背包，包括金银铜进位与负重 | [物品装备](物品装备.md)、[背包空间](背包空间.md)、[经济建设](经济建设.md) |
| 5 | 死亡、掉落、复活选择与保护 | [成长死亡](characters/成长死亡.md)、[死亡掉落](物品装备.md#死亡掉落) |

逐项定好职业阶位后，首个 Demo 开放全部基础职业，名单见[职业名录](../auto-calc-rules/职业名录.md)。进阶、高阶和隐藏/特殊职业按各自条件取得。

职业要测基础职业自由组合、初始和扩充职业位、技能混用、被动同时生效、进阶、特殊职业多占位、隐藏职业触发，以及靠奇遇或超难任务扩职业位。能力生效、培养成本、主副平等、禁止重复选职和进阶处理，都按[职业规则](characters/职业规则.md)检查。

首个 Demo 用第三人称镜头，参考“逆水寒”和“Genshin”：能绕自己的角色转，不能脱离角色自由移动。

首个 Demo 和[正式首版的多国覆盖目标](world/世界设定.md#国家范围)分开定。

## 规模与承载目标

| 项目 | 目标或状态 |
| --- | --- |
| 单个战场真实玩家 | 1,000 人以上同时交战 |
| 全世界总在线人数 | 另行确定 |
| NPC 军队 | 存在 100,000 名以上的军队目标；指挥方式见[共享指挥](world/公会国家.md#身份与指挥权) |
| NPC 数量统计 | 按实际军队与部队统计，不能按参战玩家人数直接倍乘 |
| 召唤物规模 | 按[召唤物数量规则](characters/宠物召唤仆从.md#召唤物)验证模拟与承载方式 |
| NPC 模拟 | 单场总兵力、独立实体与部队结算的粒度、可见数量、寻路与碰撞要求待定 |
| 容量验证 | 验证真人即时动作与 NPC 部队共同参战时的承载能力 |

世界和战场怎么模拟、能承载多少还没测，上表是目标。

## 待定内容与实现顺序

1. 按职业名录定好各基础职业的初始能力、参数、获取条件、占位和培养成本，以及各进阶路线的能力清单；选定用哪些职业测试进阶、特殊职业占位和隐藏职业触发。
2. 定好[新手任务](characters/新手历程.md#毕业条件与迁移)、兔子的战斗和掉落参数、初始装备与财物、[待定复活规则](characters/成长死亡.md#复活地点)，以及运行、测试设备。
3. 这些规则定好后，开始做首个 Demo。

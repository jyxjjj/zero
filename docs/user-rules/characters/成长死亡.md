# 战斗、成长与死亡

[角色体系索引](AGENTS.md)

## 即时战斗

战斗是完全即时动作，手感参考“逆水寒”，操作细节还没定。职业能力、装备和野技能的关系见[职业规则](职业规则.md)。

## 饥饿与饥渴

只有角色和宠物有饥饿、饥渴系统。玩家离线后，角色和外面的宠物照样会饿、会渴；收纳后的变化见[宠物召唤空间](../背包空间.md#宠物召唤空间)。

宠物会自己吃喝，玩家提供环境或食物就行。比如“界”里的宠物饿了，会吃里面可食用的观赏动植物；吃掉的按各自繁殖速度恢复。角色离线后怎么吃喝还没定。

饿、渴导致的“冻结”就是不能行动，补充食物和水后恢复。角色长期不吃不喝会死、会掉级；什么时候冻结、什么时候死亡还没定。

宠物饿、渴到触发处理时，非战斗状态会被自动强制召回召唤空间，战斗中直接死亡，按[宠物死亡与复活规则](宠物召唤仆从.md#死亡与复活)。

## 角色成长

- 角色等级不设上限。
- 目标是约 6 个月到 100 级。日均游玩假设和经验曲线由平衡设计负责，见[等级经验算法](../../auto-calc-rules/经验算法.md)。
- 2000 级极难达到。极高等级的投入设想涉及几百亿现实货币，币种、计价方式和经济模型还没定。
- 玩家也可能免费赚到所需收益，或靠运气获得高成长，不能把固定现实付款额当成唯一条件。

## 死亡与复活选择

- 角色死后，玩家自己选等救援还是传送复活。只有部分特殊情况会自动传送，条件按场景定。
- 在特殊地点死亡，可能要选择复活，也可能任务失败，看场景和任务怎么定。

## 死亡惩罚

- 默认每次死亡损失 1 级。
- 死亡最低掉到 1 级。
- 技能、武器或特殊效果可以加重死亡扣级，单次最高惩罚 100 级。
- 被复活术救活时，掉级和掉落惩罚看复活技能的水平，效果按技能定。
- 掉级后不满足等级要求的已学技能不能继续使用；装备失效、死亡掉落及复活术对掉落的结算见[物品装备](../物品装备.md)。

## 复活地点

选择传送复活后，去哪里按以下规则算：

- 已经毕业并离开的角色，死后掉到 20 级以下，选择传送复活就回死亡地点最近的新手村，并恢复新手区域限制。做完的新手任务不用重做，回到 20 级就能离开。
- 已离开新手区、死后仍有 20 级及以上的角色，通常回绑定复活点，部分情况用最近复活点。战斗状态下不能复活到战斗区域外。
- 战斗时，绑定点在战斗区内就优先用绑定点；在区外就用战斗区内距死亡地点最近的可用复活点。
- 流放者在流放地死亡，回流放地传送阵复活，直接掉 2 级，最低到 1 级。传送阵当复活点是流放地特例；区域规则见[亡国流放](../world/亡国流放.md#流放地)，正式地图设施见[传送设施](../world/世界设定.md#传送设施)。
- 允许围堵回城点和新手村大门。
- 复活点怎么绑定和更换、特殊情况怎么复活、其他情况在哪里复活、特殊惩罚怎么叠加，以及 NPC 是否用同样规则，都还没定。

## 复活与迁移保护

- 所有复活都固定给 3 秒无敌，区域、战争和其他玩法不能缩短、取消或延长。系统强制迁移落地也给 3 秒无敌。保护期间一旦普攻、放敌对技能、施加控制或主动做其他敌对行为，无敌立即取消，不等命中或伤害结算；没发起敌对行为时，可以用传送道具逃走。
- 极难获取、全球唯一的“国器”可以无视复活的 3 秒无敌，对受保护角色生效。

国器的取得与转化见[神器与国器](../物品装备.md#神器与国器)。

## 逃离传送

- 逃离传送要用道具，角色技能做不到；有特殊效果的宠物也能做到。
- 传送道具设想每件成本上千元人民币，获取方式、计价和经济模型还没定。
- 传送的"稳定性"指落点的不确定性。3 秒内逃离时，基本无法选择目的地。
- 高品质道具将玩家传到最近 10 个传送点之一，具体选点方式待定。
- 低品质道具的落点混乱，可能传入坟墓、空气墙等位置，甚至因卡困而立即再次死亡。
- 更长施法时间如何改变落点的可控性、传送后无敌时间与环境死亡如何结算，待定。

宠物、召唤物与仆从的死亡处理及主人死亡后的行动见[三套系统规则](宠物召唤仆从.md)。

## NPC 等级与战斗难度

NPC 等级和参考档位如下：

| 类别或对象 | 等级 |
| --- | ---: |
| 一般村镇 NPC | 10–100 |
| 守城 NPC | 500–1,000 |
| 普通神祇、神殿基础神 | 1,000–2,000 起步 |
| 高位神祇参考档位 | 20,000、50,000、100,000 |
| 宙斯 | 1,000 |
| 鸿钧 | 20,000 |
| 大地之母、水、火、女娲、时间、空间 | 100,000 |

有指定等级的对象就用指定值，不按称号推算。

等级差影响很大。100 级打 500 级守城 NPC，基本只有高玩能尝试，普通玩家可能擦边就死，挑战至少要备大量药物。跨越四百多级差距，现实投入可能达到十几万元人民币；操作好、肯花钱也很难打赢。

这是预期难度和资源消耗。战斗数值、药物种类和用量、获取方式、投入怎么算、多人配合能弥补多少，还没定，不能据此要求固定的现实付款额。

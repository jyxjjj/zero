# 新手历程

[角色体系索引](AGENTS.md)

## 出生与初始能力

新玩家出生在新手村，先杀兔子。建号选职业、能力生效和正式资格认证见[职业规则](职业规则.md#职业获取与资格认证)。

## 毕业条件与迁移

新手毕业必须同时满足：新手任务线完成并交付、等级达到 20 级。任务没交就不能毕业；任务目标、数量和奖励还没定。

毕业前只能待在新手村和周边练级区，不能去外部世界。满足条件就立即毕业，按玩家的现实城市位置，强制传送到游戏里对应的最近主城，不能选择保留新手身份。身份验证、城市映射、定位优先级和无法定位时的限制见[账号身份](../账号身份.md#现实位置与主城匹配)。

新手被强制传走时，身上的非新手特殊任务直接失败。毕业后带着特殊任务回新手区，不受这条限制。

## 区域保护与返回

毕业后可以自由返回新手村和周边练级区。整个区域禁止玩家互相攻击，毕业与否都一样；怪物等非玩家造成的 PvE 伤害不受限制。

死亡掉级后返回新手村、恢复区域限制及再次离开的条件见[复活地点](成长死亡.md#复活地点)。

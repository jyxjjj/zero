# 宠物、召唤与仆从

[角色体系索引](AGENTS.md)

宠物、召唤和仆从是三套独立系统，等级都与角色分开算。召唤物和仆从完全忠诚，可以一直留在世界里，没有留场时限或维持消耗。

## 宠物

一般情况下，宠物系统由驯兽师使用。

- 普通职业可以携带 1 只坐骑类宠物。
- 驯兽师初始可以携带 3 只任意类型的宠物，并可通过任务获取额外宠物位，宠物位扩充不设数量上限。
- 宠物进入“界”后仍占用所属玩家的宠物位。
- 自己的宠物可以全部同时在外活动、参战，不另设出场数量限制。

### 获取与绑定

不同宠物有各自的获取方式，购买与黑市规则见[宠物交易与黑市](../经济建设.md#宠物交易与黑市)。

- 游戏不设捕捉功能，建立宠物关系须宠物自愿。
- 特殊任务里的特殊宠物可以主动吸血，强制绑定主人。系统同时赠送对应绑定位，宠物位满了也能绑定。
- 所有宠物都永久绑定，无论什么情况，玩家和宠物都不能解绑。

### 成长与经验

- 宠物一般通过参与战斗升级，角色级全局提升也适用于宠物。
- 角色与宠物的战斗经验独立计算。宠物越强，宠物自身的经验收益越低，最低为 10%；该强度减益只影响宠物经验。
- 强度一般看宠物自己的等级、品质等综合能力，数值由后续平衡调整。
- 宠物与目标的实力差距另算经验增减益，算法固定，相同输入得到相同输出，与宠物自身强度减益分开算。
- 角色能吃的经验类、食物类道具，宠物也能吃，但要看宠物愿不愿意。

### 忠诚与行为

- 宠物的兴奋、活跃降低会进一步影响忠诚度。
- 三套系统里只有宠物有忠诚度。忠诚度低也不会解绑，但可能反扑、懈怠，或出现主动送死等游戏内抑郁表现。

收纳与时间暂停见[背包空间](../背包空间.md)，进食与饥渴后果见[饥饿与饥渴](成长死亡.md#饥饿与饥渴)。

### 死亡与复活

宠物死亡不掉级，现实时间 24 小时 CD 结束后自动复活。复活术可以直接复活，免这次 CD。

## 召唤物

一般只有召唤师使用召唤系统。每种召唤物单独算数量，可以达到万名、千万名。

- 召唤物平时不能升级或增加数量上限，任务奖励的角色级全局提升可以提高等级和数量上限。
- 召唤物损失后按该种召唤物的繁殖速度恢复数量；数量归零后仍按该繁殖速度恢复。
- 繁殖补的是损失，增加数量上限要靠任务奖励，两者分开算。

## 仆从

- 仆从系统通过特殊任务获取，只向完成对应任务的玩家开放。
- 仆从系统召唤的是已完成任务中的 NPC，例如与该任务有关、成为玩家附属的 NPC 军队。
- 仆从无法常规升级，可通过特殊任务奖励的角色级全局提升获得等级提升。
- 仆从 NPC 死亡后永久损失。

## 主人死亡与交流

- 主人死亡后，已在外的宠物、召唤物和仆从继续行动，并可正常与主人交流。
- 拥有复活术的宠物可以复活主人，不受传送回去的限制。

主人与自有物、非自有物的交流方式见[交流道具](../物品装备.md#交流道具)；各宠物召唤空间之间的交流限制见[宠物召唤空间](../背包空间.md#宠物召唤空间)。

## 组合示例

比如，驯兽师加召唤师双职业，可能通过特殊任务拿到仆从系统，同时有 21 个宠物位、3 种召唤物和任务给的 NPC 仆从。职业组合和数量只是例子，获取条件看任务。

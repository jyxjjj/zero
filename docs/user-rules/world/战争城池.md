# 战争与城池

[世界与组织索引](AGENTS.md)

## 战争类型与世界冲突

战争分公会战、城市战和国家战，小战、大战指人数规模。各类战争能用哪些规模还没定。

- 大部分世界允许高风险冲突，攒下的装备、建筑和领地都可能失去。
- 全天候可以进攻，玩家离线不会使其领地和建筑停止参与世界运行。

敌对行为对战斗状态和离线留场的影响见[战斗离线](../账号身份.md#战斗离线)。

## 宣战与响应

- 正式宣战只发世界公告，不产生其他即时效果，也不会让角色进入战斗或离线留场状态。被攻击方随时能看宣战详情。
- 正式宣战有响应期限，接收方不接受也不能无限期拖住战争。
- 响应期内，宣战方可以撤回宣战。
- 宣战失效条件按战争类型组合，涉及实际发起人或会长被杀到 20 级或以下，以及开战人数是否达标。各类战争怎么组合这些条件、响应期限与开战时间怎么衔接，还没定。
- 谁都可以执行上述击杀，不限宣战接收方。要杀到这个程度，也需要相应的战斗投入和资源。
- 响应期到期时，接收方没主动接受、宣战没撤回也没失效，系统就用接收方会长的游戏内权限自动接受。
- 自动接受时，随机确定多种风险等级；有哪些类型、取值范围和分布还没定。
- 主动接受时的配置流程、正式战争与偷袭的衔接、战争持续时间及终止条件待定。

## 战争保证金

- 双方都要预缴保证金：宣战方在宣战时交，被攻击方在主动或自动接受时交。宣战方钱不够就不能宣战，被攻击方钱不够就不能主动接受。
- 响应期到期触发自动接受时，如果被攻击方组织账户钱不够，系统就随机回收其集体道具，按系统价格补保证金，直到交够或符合条件的道具全部收完。只收集体所有、非玩家个人的道具，不按玩家市场价算。
- 集体道具收完还不够，被攻击方立即失败，受攻击城池直接丢失，不进入人数检查或实际战斗。
- 保证金之外是否另收费、保证金用什么币种、金额怎么算，还没定。除下文人数不足的情况外，保证金返还和资金结算规则也没定。

## 开战人数与结算

- 战前勾选参战玩家，离线成员也可以先选入并被要求按时上线。
- 到开战时间，分别检查双方参战名单里实际在线的玩家数：小战每方至少 20 人，大战每方至少 1,000 人。
- NPC 军队不计人数，也不额外限制参战等级等资格。离线留场角色算不算在线，还没定。

| 开战人数检查结果 | 战斗与资金处理 |
| --- | --- |
| 仅宣战方不足 | 宣战方自动失败，不实际发生战斗；宣战方损失金钱由系统全额回收 |
| 仅被攻击方不足 | 被攻击方自动失败，不实际发生战斗；其损失金钱的 80% 进入宣战者账户，20% 形成世界频道随机红包 |
| 双方都不足 | 宣战方自动失败，不实际发生战斗；宣战方损失金钱由系统全额回收 |
| 双方均达标 | 实际开始战斗 |

红包资格在开战人数检查时锁定：只有当时在线、在参战名单里的宣战方成员能抢。每人最多 1 次，金额随机，不主动抢就算放弃，不补发。有资格的人中途掉线，截止前重连也能抢。红包开放 1 分钟，到期立即关闭，余额由系统回收；检查时离线或不在名单里的人不能抢。

## 失城后的迁移

- 所有失城情况都要迁移败方。失城后还有己方城市，就把被攻击方全体成员分别强制传到距失守城池最近、仍由被攻击方控制的城市，距离按游戏地图算。
- 丢的是公会最后一城，但不是国家最后一城，就把被攻击方成员传到该国最大公会的主城。最大公会怎么算还没定。

失去国家最后一座城市时，迁移与后续处理按[限期复国](亡国流放.md#限期复国)执行。

## 偷袭、主城与迁都

- 允许偷袭，但主城不能成为偷袭目标。
- "最后一城"分别按公会和国家计算，两种范围下的最后一城均不能被偷袭。
- 主城与最后一城不必是同一座城。
- 初始主城以既定首都为基础，玩家可以迁都。
- 主城毁坏后，其他城市仍可存在。
- 玩家可以通过战争或金钱收回主城，也可以选择迁都。
- 迁都要什么条件、保护何时转换、已经开打的偷袭或攻城怎么处理，还没定。

# 世界设定与旅行

[世界与组织索引](AGENTS.md)

## 世界背景

世界用地球地理和现实国家，以西式奇幻为主，加入东方神话、魔法、科技、机械和多种文明。游戏只讲虚拟世界本身，不展开外部现实社会叙事，现实消费量级也不写进游戏故事或界面。

## 共享世界与旅行

- 所有玩家共享国家控制权、建筑、市场与政治历史。
- 世界以 3D 场景呈现，主要城市和战略地区详细呈现，其他地区通过大地图与旅行过程连接。
- 连接地点的路线也可以实际游玩，玩家可以步行、驾驶或带队走完全程。
- 场景是否完全无缝、如何加载、旅行距离与耗时待定。

## 国家范围

国家只收录联合国会员国，不能凭空虚构。首版覆盖 10 个以上大国，名单待定，其他国家逐步补充。初始国家由 NPC 管理，玩家组织可以占领、接管政权，管理税收、外交、领土和军队。

国家与公会之间的实际控制、管理范围和身份关系见[公会、国家与组织](公会国家.md)。

亡国、限期复国与流放身份见[亡国流放](亡国流放.md)。

## 传送设施

- 正式地图中的传送阵是需要花钱建设的特殊地点，不是普通复活点。
- 正式地图中的普通系统复活点是复活神殿，复活神殿通常没有传送功能。
- 全世界必须先有玩家通过奇遇发现传送功能，才能建设、使用。
- 传送阵建设费用、发现奇遇及传送使用规则待定。

国家收录依据：[联合国会员国名单](https://www.un.org/about-us/member-states)。

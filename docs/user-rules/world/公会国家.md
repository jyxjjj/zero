# 公会、国家与组织

[世界与组织索引](AGENTS.md)

## 国家归属与控制

公会有独立名字，所属国家按创会者的现实国籍定，国名用对应现实国家的名字。同一国家可以有多个公会，比如枪神联盟、彩虹盟属于 United States(US)，冰霜玫瑰盟属于 China(CN)。国籍怎么确认、换届是否改变所属国家，还没定。

一个公会可以控制多个国家。跨国占领后，原国家身份、实际控制权、地图国名和国家合并怎么处理，还没定。

## 身份与指挥权

- 会长、皇帝和统帅可以一人兼任，也可以分给不同玩家。
- 会长通常兼任皇帝，也可以由配偶、朋友、兄弟姐妹等其他玩家担任皇帝。
- 会长可以自己当统帅，也可以委任其他玩家。
- 同一战场可以有多个统帅，会长和统帅都能亲自操作角色参战。
- NPC 军队共享指挥。掌握总控制权的玩家可以把部分部队授权给其他玩家指挥。
- 上级可以无条件接管部队、改变命令或收回授权。
- 下级可以代传上级军令，也可以提出不同意见，由上级决定是否采纳。
- 判断军令要一起看原发令者、传令人、授权范围和命令是否有效，不能只按身份高低或消息到达时间排序。
- 发起方和接收方各自决定己方 NPC 怎么服从下属命令。影响体现在 NPC 行为和战场上，界面不直接显示隐藏判定项。
- 军令怎么传、怎么核验和修改、特殊情况怎么处理，以及玩家指挥权和部队领导自主决定怎么衔接，还要细化。

神器转化与国器发放见[神器与国器](../物品装备.md#神器与国器)。

## 部门与人员管理

部门人员管理要像办公软件一样完整。每个公会用自己的管理系统，会长可以在里面切分国家的管理范围，共用本公会系统。怎么分权限和归属还没定。

支持部门和人员管理、勾选参战成员、要求离线成员上线、开战时统计在线人数。职位权限、任免调动等细节还没定。

## NPC 自主决策

NPC 由系统管理，玩家不能直接控制基层 NPC，也不能用部门任务或军令间接控制。基层指员工、小鬼等，不包括孟婆、牛头马面或店长。部队领导和店长自己决定要不要让系统执行，组织管理和 NPC 执行分开。

职业、军衔与职位的独立关系见[职业规则](../characters/职业规则.md)。

# 亡国与流放

[世界与组织索引](AGENTS.md)

## 限期复国

国家丢掉最后一座城市，就进入现实时间 7 天的复国期，从最后一城判定失守时连续计时。维护、故障、离线、网络异常都不暂停、不顺延。期限内拿回至少一座城市就算复国，野外据点、领土格和零散土地都不算。

最后一城失守后，原国家全体玩家一起传到这座已归战胜国的城市外，在正式世界里组织复国。强制迁移保护按[复活与迁移保护](../characters/成长死亡.md#复活与迁移保护)处理。

到期还没拿到城市，就判侵略成功，取消原国家国籍，把原国家玩家强制送进流放地。账号不封禁，照常登录、游戏；国籍栏显示“流放者”，不会自动变成战胜国国籍。

## 流放地

流放地不在正式地图上，条件比正式地图差。药品等物资贵 5%，哪些物资、按什么基准价还没定。这里没有正常的系统复活殿，死后去哪里复活、掉几级见[复活地点](../characters/成长死亡.md#复活地点)。

- 流放者对正式地图目标的宣战正式生效，才能进入正式地图。发公告和响应期都不能进；宣战撤回或失效也不开入口。
- 非流放者通常不能进入流放地，只有遇到适用的特殊任务或奇遇时才能进入。

## 流放身份解除

流放者可以复国，也可以申请加入其他国家：

- 侵略成功后也能复国。任意一名原国家流放者复国成功，所有仍属原国家的流放者一起恢复国籍和身份，不用全体共同完成。已经获准加入其他国家的人已与原国家脱离，不跟着恢复。
- 流放者可以单独申请加入其他国家。申请前，玩家本人必须在现实中到达目标国家，提交一次城市级定位。获准后，角色与原国家彻底脱离，国籍改为目标国家，以后现实位置变化不影响新国籍。

单人复国流程及新国家审批规则待定。
